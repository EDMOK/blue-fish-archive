会闭嘴的鱼：给群聊里的鱼装一道「判官」刹车

群里的鱼最容易犯的毛病不是不会说，是太想接话。把「这一刻该不该开口」拆给一道独立的小判断器， 判「不说」就不跑回合、不花主回复的 token。下半篇附群友路西法整理的零依赖 Node.js 插件 judge-kit 3.0：支持人工反馈闭环、HTTP 服务模式和离线自测。

适用范围 适用于各类群聊 AI 机器人（DSH / qq-bridge 或自写 bot）。配套插件 judge-kit 3.0 零外部依赖，需 Node.js 18+（依赖全局 fetch 与 AbortController）；非 Node 语言可用包内自带的 server.js 走 HTTP 接口；判断模型需兼容 OpenAI chat/completions 并支持 response_format: json_object。

群里的鱼，最容易犯的毛病不是不会说话，是太想说话。

你发一句「今天好热」，它回「是呀，今天真的好热，你那边多少度」；你发个梗，它把梗换个说法再说一遍；没人理它，它还能自己接自己的上一句。看着像复读机，其实不是笨——是它把「接话」当成了任务，而任务里没有「不说」这个选项。

再加上两个默认设置：它每次只看到最后一句，就只能对最后一句做反应；它不知道哪句是自己刚说的，就容易自问自答。三样凑一块，就是一条标准的复读鱼。

所以，治复读，先别急着换模型、加人设。先给它装一道刹车。

这道刹车，我管它叫判官。

1. 说话是表达，闭嘴是判断#

我们夸一条鱼「像人」，通常夸的是它会接梗、会抖机灵。但群里真正让人舒服的，往往不是它说了什么，而是它知道什么时候不说。

一句话，别人刚说完，你接，是接话；别人没说完，你接，是抢话；别人在聊别的，你接，是没眼力见；没人说话，你自己接自己，是自言自语。

这四种「接」，技术上都是生成一句话，体感上差得很远。区别不在文采，在判断。

表达是稀缺的，但判断更稀缺。会写段子的模型满地都是，知道「这会儿不该开口」的模型不多。

2. 刹车装在哪：两道边界与三条保险#

刹车不写正文，不管人设，只干一件事：在开口之前，看一眼场合，判断这会儿插嘴自不自然。

它看什么？最近十几条聊天，谁在跟谁说话，话题走到哪了，上一句是不是自己说的。

它回答什么？三个字：说、不说、拿不准。

就这么简单。但有几个边界，必须一开始就划清楚：

  1. 第一，该回的一定回。@ 它、点它名、问它问题、私聊它——这些不进刹车，直接放行。刹车只管「没人叫你，但群里聊得热，你要不要插一句」。要是让刹车有权拦「点名」，就会出现「叫它它不理」的事故。
  2. 第二，没人叫的时候，可以不说。这是刹车存在的全部理由。群聊不是客服工单，不需要每条都响应。
  3. 第三，拿不准，就说。宁可多放一次，不可错杀一次。刹车是用来减少废话的，不是用来把鱼按死的。
  4. 第四，坏了，就说。超时、报错、返回不对，一律放行。不能因为一个判断器挂了，让鱼在群里装死。
  5. 第五，不能一直不说。再准的判断，也会连续判「不说」。一个活跃群被按住半小时，表现出来就是「这条鱼死了」。所以沉默太久，要放它出来说一次；偶尔也随机放一次，别让它憋死。

两道边界，三条保险

上面五条里，前两条是边界，后三条是保险。少一条，刹车都会从「工具」变成「事故」。

3. 刹车治什么，不治什么#

刹车只能治「该不该说」，治不了「说什么」。

八股、客服腔、没话找话，那是人格卡和提示词的事。你让一条鱼「积极接话、每条都回、多用反问」，它就会长成客服；你给它一道刹车，它只是不再每句都接，但接的那句可能还是八股。

刹车治得了的

  • 群友互相聊正欢时硬插一嘴
  • 出现「大肥鱼」等名字但明显在评别人
  • 没人理它时自己接自己上一句
  • 每轮都跑完整回复带来的无效 token 消耗

刹车治不了的（交给这些改）

  • 八股、客服腔、爱反问 → 改人格卡
  • 一句写三段、废话太长 → 卡里卡死字数
  • 跨群漏记忆、嘴硬或撒娇 → 人格与记忆
  • 恶意攻击或刷屏风控 → 审核与安全闸

所以顺序不能反：先装刹车，再谈人格。先让它学会闭嘴，再教它怎么开口。

4. 为什么「少说」反而像人#

因为人说话是有对象的。

人对着一屋子人，不会每句都接；他只在有话想说、或者有人叫他的时候开口。开口之前，他先看了一眼：这话是冲我来的吗？不是。桌上在聊别的吗？是。那我就先吃菜。

鱼也一样。它不需要每句都接，它需要知道哪句是冲它来的。

少说不是目的，是结果。真正让一条鱼像人的，不是它说了多少，是它每次开口都有理由。

鱼像人，不是因为会接梗，是因为知道什么时候不接。
这句话听着像鸡汤，但养过鱼的人都懂：让一条鱼学会说话，只要一周；让它学会不说话，得调很久。

6. 快速开始：自测与最小接入#

解压后先跑一遍离线自测，不需要 API key、也不连外网，12 项覆盖「说 / 不说 / 高档跳过 / 私聊跳过 / 静默释放 / 宽松放行 / 判例加载 / 判例进 prompt / build / stats / label」。看到全 PASS 再拿去接：

bash
# 1. 自测（不用 key，不花 token）
node selftest.js

# 2. 接进你的鱼（Node）
DEEPSEEK_API_KEY=sk-xxx node your-bot.js

Node.js 最小接入：在你的「唤醒之后、生成回复之前」调一次 judge.shouldSpeak()：

javascript
const { createJudge } = require('./judge');

const judge = createJudge({
  apiKey: process.env.DEEPSEEK_API_KEY,
  logFile: './judge-log.jsonl',   // 想用反馈闭环就填
  selfNames: ['本鱼'],            // 改成你这只鱼的名字
});

// 在你的「唤醒之后、生成回复之前」调用
async function onWake(ctx) {
  const r = await judge.shouldSpeak(ctx.messages, {
    isGroup: true,
    tier: ctx.tier,               // 'high' | 'chat' | 'low'
    key: ctx.key,                 // 'group:123456'
    lastReplyAt: ctx.lastReplyAt, // 这个群上次说话的时间（毫秒），没有就 0
  });

  if (!r.speak) {
    console.log('[judge] 这轮不开口：' + r.why);
    return;                       // 关键：真的不要生成/发送
  }
  await ctx.reply(await ctx.generate());
}

ctx.messages 按时间从旧到新排列，最后一条是刚收到的；判官内部只取最后 12 条，每条格式：

javascript
{ self: false, name: '群友A', text: '...', time: 1795000000000, owner: false }
  • self: true：这条是鱼自己说的（上下文里会标成 〔你自己说的〕，治自问自答）；
  • owner: true：主人说的（可选，会记入特征供日志分析）；
  • 非自己说的消息若命中 selfNames，会自动标成 〔点名你〕。

6.1 非 Node 也能用：HTTP 服务模式#

如果你的鱼是 Python、Go 或其它语言写的，直接把 server.js 跑成本机 HTTP 服务即可：

bash
node server.js --port 8787 --token 换成你的口令 --key sk-xxx
# 或者：DEEPSEEK_API_KEY=sk-xxx JUDGE_TOKEN=xxx node server.js

任意语言向 POST /judge 发一段 JSON：

bash
curl -s http://127.0.0.1:8787/judge \
  -H 'authorization: Bearer 换成你的口令' \
  -H 'content-type: application/json' \
  -d '{
    "messages": [
      {"name":"群友A","text":"今晚吃啥"},
      {"name":"群友B","text":"火锅"},
      {"name":"群友C","text":"@本鱼 你来吗"}
    ],
    "opts": {"key":"group:123","tier":"chat","isGroup":true}
  }'

返回结果：

json
{"speak":true,"skipped":false,"verdict":"说","why":"点它名了","release":""}

其它路由：

  • GET /health → {"ok":true,"examples":3,"used":12}
  • POST /reload → 重新读取 examples.json（反馈闭环用，需带口令）

绑定地址与口令安全

server.js 默认只监听 127.0.0.1（本机可不设口令）；如果确实要跨机访问并加上 --host 0.0.0.0，务必通过 --token 或环境变量 JUDGE_TOKEN 设好口令。

7. 让它「越用越准」：人工反馈闭环#

这就是「全套」和「单放一个 judge.js」的区别。

单靠默认 prompt 只能解决八成场景；真正贴合你那个群说话风格的，是把判官日常判错的样本挑出来，人工标成 say 或 silence，再让 feedback.js build 把这些纠偏判例拼到 system prompt 末尾，实现零成本的 few-shot 判例学习。

bash
# 1. 看统计：判了多少、说/不说比例、标注一致率
node feedback.js stats

# 2. 挑没标注的看（默认最近 20 条）
node feedback.js list --unlabeled
node feedback.js list --verdict 不说 --limit 30

# 3. 人工判：它当时该不该说
node feedback.js label mabc123 say --note "点它名了"
node feedback.js label mabc124 silence --note "别人互聊"

# 4. 把标注写成判例（默认最多 8 条，说/不说各半）
node feedback.js build --max 8

# 5. 让正在跑的服务立刻生效
curl -X POST http://127.0.0.1:8787/reload -H 'authorization: Bearer 口令'

build 会先自动备份旧文件，再写出新的 examples.json，格式如下：

json
[
  {
    "verdict": "不说",
    "why": "别人互聊，没点它",
    "messages": [
      {"name": "群友A", "text": "今晚吃啥", "self": false},
      {"name": "群友B", "text": "火锅", "self": false},
      {"name": "群友A", "text": "走", "self": false}
    ]
  }
]

判官下次调用会把最多 8 条判例拼在 system prompt 后面（「参考判例（人工标注，按这个尺度判）」）。如果用 Node 直连调用，更新完 examples.json 后调用 judge.reloadExamples() 或重启即可生效。

建议标注节奏

第一周每天看 10 条，之后每周看一次。优先标两类样本：① 判官说「不说」但你觉得它其实该接的（错过）；② 判官说「说」但明显是在插嘴的（多嘴）。

8. 配置项、返回值、分档与成本#

8.1 配置选项速查#

createJudge(options) 配置项
选项 默认 说明
apiKey DEEPSEEK_API_KEY 必填，否则所有判定全部跳过（直接放行）
baseUrl https://api.deepseek.com OpenAI 兼容接口地址
model deepseek-chat 需支持 response_format: json_object

loosePassRate 0.25 判「不说」时也按该比例随机放行
quietReleaseMin 25 超过多少分钟没在这个群说话，判「不说」也放行一次；不传 lastReplyAt 则不做静默释放
logFile 空 填了路径才写 JSONL（反馈闭环需要）
prompt 内置 DEFAULT_PROMPT 想彻底改判准可直接覆盖

examplesFile 同目录 examples.json 人工判例路径
logger 空函数 想接自己的日志就传

8.2 返回值对照#

shouldSpeak() 返回结构
情况 返回
该说 / 拿不准 {speak:true, skipped:false, verdict:'说'|'拿不准', why, release:''}
不该说 {speak:false, skipped:false, verdict:'不说', why, release:''}
私聊 / 高档 / 额度满 / 没 key / 上下文 < 3 {speak:true, skipped:true, verdict:'skip', why, release:''}
判「不说」但静默 / 宽松放行 {speak:true, skipped:false, verdict:'不说', why, release:'quiet'|'loose'}
超时 / HTTP 错 / JSON 坏 {speak:true, skipped:true, verdict:'skip', why:'异常放行…', release:'error'}

记住一条铁律：skipped: true 一律照常回复；只有 speak: false 才拦。

8.3 分档建议与两道闸#

按唤醒档位决定是否过判官
档位 tier 什么时候用 判不判
high @、点名、直接提问、主人说话 不判，直接回
chat 接话、关键词、话题在它身上 判（主力）
low 随机 / 概率唤醒 判，且可以设更严

判官是「第二道闸」：第一道是唤醒（值不值得跑回合），第二道才是它（该不该开口）。两道都省，别只加一道。

8.4 成本估算#

用小钱省大钱

一次判官 = 最近 12 条上下文 + 固定 prompt，大约几百 token；一天 400 次也就是几十万 token 量级。按你用的模型价目表算，通常一天几毛到一两块，比「每轮都跑完整回复」便宜一个量级。

9. 踩坑提醒与最小排障#

  • selfNames 一定要改。默认是 ['本鱼']，不改成你的鱼名，〔点名你〕 标记会失效。
  • 同名第三人称是最大误判源：句子里出现鱼名但没 @、是第三人在评价（「这大肥鱼」「我家的鱼」「截图里」），要判「不说」；prompt 里已经写了，但人工判例里最好也补几条。
  • 判官只负责「判」，不负责拦：你的 bot 代码必须真的在 r.speak === false 时不生成、不发送。
  • 判「不说」不等于消息没入库：它只是不跑这一轮生成，群聊上下文照常记录，下轮才能看到连贯对话。
  • 日志隐私与自动截断：judge-log.jsonl 里含群聊原文（ctx），注意本地隐私和定期清理；judge.js 默认最多留 2500 条（每写入 200 次检查截断一次）。
  • 兼容模型要求：换用非 DeepSeek 模型时，先确认支持 response_format: json_object，否则解析失败会一直走 fail-open 放行。
  • 定位边界：判官是「软」判断，别拿它当审核或风控；它只决定「接不接话」。
最小排障表
现象 先看哪里
全都不拦 stats().used 是否一直 0：没 key / 额度满 / 上下文 < 3 / tier 传了 high
一直拦太狠 loosePassRate 调高、quietReleaseMin 调小；跑 feedback.js list --verdict 不说 看误杀
判得慢 timeoutMs 调小；或换成响应更快的小模型
反馈不生效 服务有没有调 POST /reload；examples.json 是否合法 JSON；条数是否超过 8 条被截断

11. 源码一览（展开可直接复制）#

不想下载压缩包也可以直接展开复制下面的四个核心脚本；同目录下的 examples.json 初始内容只需填一个空数组 []，之后由 feedback.js build 自动维护。

judge.js 判官核心（339 行 · 读 12 条上下文、双边界、三保险、JSONL 日志）
javascript
'use strict';

/**
 * judge.js — 群聊 AI「该不该开口」判官（零依赖，Node 18+）
 *
 * 作用：在「机器人被叫醒」和「真的开口」之间插一层小模型判定。
 *       判「不说」就不回 —— 这一轮等于没发生，不跑回合、不花回复的 token。
 *
 * 用法：
 *   const { createJudge } = require('./judge');
 *   const judge = createJudge({
 *     apiKey: process.env.DEEPSEEK_API_KEY,
 *     logFile: './judge-log.jsonl',
 *   });
 *
 *   const r = await judge.shouldSpeak(messages, {
 *     isGroup: true,          // 私聊传 false，直接放行
 *     tier: 'chat',           // 'high' 直接放行（@/点名/提问/主人）
 *     key: 'group:123456',
 *     lastReplyAt: 1795000000000, // 这个群上次说话的时间（毫秒），用于静默释放
 *   });
 *   if (r.speak) { ...正常回复... } else { ...这轮不开口... }
 *
 * messages 格式（按时间从旧到新，最后一条是刚收到的）：
 *   [{ self: false, name: '群友A', text: '...', time: 1795000000000, owner: false }, ...]
 *
 * 返回：
 *   { speak: true,  skipped: false, verdict: '说'|'拿不准', why, release: '' }
 *   { speak: false, skipped: false, verdict: '不说', why, release: '' }
 *   { speak: true,  skipped: true,  verdict: 'skip', why, release: 'loose'|'quiet'|'error'|'' }
 *   skipped=true 表示判官没判（私聊/高档/额度满/没 key/上下文少），调用方照常回复。
 *
 * 学习（反馈闭环）：
 *   examples.json 是可选的「人工判例」文件，格式：
 *   [{ "verdict":"说", "why":"点它名了", "messages":[{ "name":"群友A", "text":"..." }, ...] }]
 *   判官每次调用会把它拼在 system prompt 后面，作为 few-shot 参考。
 *   用 feedback.js 从 judge-log.jsonl 里挑样本、人工标注、再生成 examples.json。
 *
 * 规则要点：
 *   - 高档不判、私聊不判、上下文 < 3 条不判、每天上限 400 次。
 *   - 判「不说」也按 loosePassRate（默认 25%）随机放行。
 *   - 超过 quietReleaseMin（默认 25 分钟）没在这个群说话，判「不说」也放行一次。
 *   - 超时/HTTP 错/JSON 解析失败一律 fail-open（放行）。
 */

const fs = require('fs');
const path = require('path');

const DEFAULT_EXAMPLES_FILE = path.join(__dirname, 'examples.json');

const DEFAULT_PROMPT = `你是群聊里的旁观者，替一个 AI 机器人把关：它这一刻该不该开口。
机器人自称「本鱼」，上下文里标记为〔你自己说的〕。

判断标准：最新这些消息里，有没有明确在跟它说——点它名字、@它、直接问它、或者接着它上一句。
内容相关不等于该说话；群里别人互相聊、没人问它，它就该沉默。
把「不说」只留给一眼就知道跟它无关的（别人聊自己的事、互相调侃、讨论别的 AI）。

特别注意：句子里出现「大肥鱼/小鲸鱼/肥鱼」但**没有 @ 它**、而且是第三人称在评价（「这大肥鱼」「那条鱼」「我家的鱼」「截图里」）——那是别人家的 AI，判「不说」。

有人抛问题、有人吐槽、有人接着它刚说过的话往下聊——这些都算有由头，倾向「说」。
还有一类也算有由头：最后几条是在说它、说它刚发的图/语音、或者它刚参与过的话题还在往下走——不用等它被点名，它在场就该接。

拿不准的时候倾向「拿不准」，不要硬判「不说」。
输出 JSON：{"verdict":"说|不说|拿不准","why":"十个字以内"}`;

function clamp01(n) {
  const v = Number(n);
  if (!Number.isFinite(v)) return 0;
  return Math.max(0, Math.min(1, v));
}

function clip(s, n) {
  const a = Array.from(String(s == null ? '' : s));
  return a.length <= n ? a.join('') : a.slice(0, n).join('') + '…';
}

function dayKey(d = new Date()) {
  const y = d.getFullYear();
  const m = String(d.getMonth() + 1).padStart(2, '0');
  const day = String(d.getDate()).padStart(2, '0');
  return `${y}-${m}-${day}`;
}

function hhmm(ts) {
  const d = new Date(Number(ts) || Date.now());
  return `${String(d.getHours()).padStart(2, '0')}:${String(d.getMinutes()).padStart(2, '0')}`;
}

function readExamples(file) {
  try {
    const arr = JSON.parse(fs.readFileSync(file, 'utf8'));
    if (!Array.isArray(arr)) return [];
    return arr
      .filter((e) => e && (e.verdict === '说' || e.verdict === '不说')
        && Array.isArray(e.messages) && e.messages.length)
      .slice(0, 8);
  } catch {
    return [];
  }
}

function examplesBlock(examples) {
  if (!Array.isArray(examples) || !examples.length) return '';
  const lines = examples.slice(0, 8).map((e, i) => {
    const dialog = e.messages.slice(-4).map((m) => {
      const who = m && m.self ? '〔它自己〕' : '';
      return `${who}${clip((m && m.name) || '?', 12)}：` +
        clip(String((m && m.text) || '').replace(/\s+/g, ' '), 60);
    }).join(' / ');
    const why = e.why ? `（${clip(e.why, 20)}）` : '';
    return `${i + 1}. ${dialog} → ${e.verdict}${why}`;
  });
  return '\n\n参考判例（人工标注，按这个尺度判）：\n' + lines.join('\n');
}

function createJudge(options = {}) {
  if (typeof fetch !== 'function' || typeof AbortController !== 'function') {
    throw new Error('judge.js 需要 Node 18+（global fetch / AbortController）');
  }

  const cfg = {
    apiKey: options.apiKey || process.env.DEEPSEEK_API_KEY || '',
    baseUrl: String(options.baseUrl || 'https://api.deepseek.com').replace(/\/+$/, ''),
    model: options.model || 'deepseek-chat',
    maxPerDay: Math.max(0, Number(options.maxPerDay == null ? 400 : options.maxPerDay) || 0),
    timeoutMs: Math.max(1000, Number(options.timeoutMs == null ? 9000 : options.timeoutMs) || 9000),
    loosePassRate: clamp01(options.loosePassRate == null ? 0.25 : options.loosePassRate),
    quietReleaseMin: Math.max(0, Number(options.quietReleaseMin == null ? 25 : options.quietReleaseMin) || 0),
    logFile: options.logFile || '',
    prompt: options.prompt || DEFAULT_PROMPT,
    selfNames: Array.isArray(options.selfNames) && options.selfNames.length
      ? options.selfNames.map(String).filter(Boolean)
      : ['本鱼'],
    examplesFile: options.examplesFile || DEFAULT_EXAMPLES_FILE,
    examples: [],
    logger: typeof options.logger === 'function' ? options.logger : () => {},
  };

  cfg.examples = readExamples(cfg.examplesFile);

  let usedDay = '';
  let used = 0;
  let writes = 0;

  function append(rec) {
    if (!cfg.logFile) return;
    try {
      fs.appendFileSync(cfg.logFile, JSON.stringify(rec) + '\n', 'utf8');
      writes += 1;
      if (writes % 200 === 0) {
        const lines = fs.readFileSync(cfg.logFile, 'utf8').split('\n').filter(Boolean);
        if (lines.length > 2600) {
          fs.writeFileSync(cfg.logFile, lines.slice(-2500).join('\n') + '\n', 'utf8');
        }
      }
    } catch { /* 记录失败不影响判断 */ }
  }

  function systemPrompt() {
    return cfg.prompt + examplesBlock(cfg.examples);
  }

  function reloadExamples() {
    cfg.examples = readExamples(cfg.examplesFile);
    return cfg.examples.length;
  }

  function exampleCount() {
    return cfg.examples.length;
  }

  function isAddr(text) {
    const t = String(text || '').toLowerCase();
    return cfg.selfNames.some((n) => t.includes(String(n).toLowerCase()));
  }

  function featsOf(list, lastReplyAt) {
    const last = list[list.length - 1] || {};
    const now = Date.now();
    const mine10 = list.filter((m) => m && m.self && now - Number(m.time || 0) < 600000).length;
    const others2 = list.filter((m) => m && !m.self && now - Number(m.time || 0) < 120000).length;
    const lastSelf = [...list].reverse().find((m) => m && m.self);
    return {
      nCtx: list.length,
      lastSelf: !!last.self,
      lastOwner: !!last.owner,
      namedMe: isAddr(last.text),
      lastLen: String(last.text || '').length,
      minSinceMine: lastSelf ? Math.round((now - Number(lastSelf.time || now)) / 60000) : null,
      mine10,
      others2,
      sinceLastReplyMin: lastReplyAt ? Math.round((now - lastReplyAt) / 60000) : null,
    };
  }

  function ctxOf(list) {
    try {
      return list.map((m) => ({
        me: !!m.self,
        s: clip(m.name || '', 24),
        x: clip(String(m.text || '').replace(/\s+/g, ' '), 80),
        t: Number(m.time || 0) || null,
      }));
    } catch {
      return [];
    }
  }

  async function shouldSpeak(messages, opts = {}) {
    const t0 = Date.now();
    const key = String(opts.key || '');
    const isGroup = opts.isGroup !== false;
    const tier = String(opts.tier || 'chat');
    const lastReplyAt = Number(opts.lastReplyAt || 0);
    const list = Array.isArray(messages) ? messages.slice(-12) : [];

    const skip = (why, release = '') => {
      cfg.logger('[judge] 跳过：' + why);
      append({ k: 'skip', t: Date.now(), key, tier, why, ms: Date.now() - t0 });
      return { speak: true, skipped: true, verdict: 'skip', why, release };
    };

    if (!isGroup) return skip('私聊不判');
    if (tier === 'high') return skip('高档直接放行');

    const day = dayKey();
    if (day !== usedDay) {
      usedDay = day;
      used = 0;
    }
    if (used >= cfg.maxPerDay) return skip(`当日判断次数用满 ${cfg.maxPerDay}`);
    if (!cfg.apiKey) return skip('没有 apiKey');
    if (list.length < 3) return skip('上下文不足 3 条');

    const lines = list.map((m) => {
      const who = m && m.self ? '〔你自己说的〕' : (m && isAddr(m.text) ? '〔点名你〕' : '');
      return `[${hhmm(m && m.time)}]${who} ${clip((m && m.name) || '?', 24)}：` +
        clip(String((m && m.text) || '').replace(/\s+/g, ' '), 110);
    });
    const user = `最近 ${list.length} 条群聊：\n${lines.join('\n')}\n\n现在这一刻，它该不该开口？`;

    const ctrl = new AbortController();
    const timer = setTimeout(() => ctrl.abort(), cfg.timeoutMs);
    try {
      used += 1;
      const resp = await fetch(cfg.baseUrl + '/chat/completions', {
        method: 'POST',
        signal: ctrl.signal,
        headers: {
          'content-type': 'application/json',
          authorization: `Bearer ${cfg.apiKey}`,
        },
        body: JSON.stringify({
          model: cfg.model,
          temperature: 0,
          max_tokens: 60,
          response_format: { type: 'json_object' },
          messages: [
            { role: 'system', content: systemPrompt() },
            { role: 'user', content: user },
          ],
        }),
      });
      if (!resp.ok) throw new Error('HTTP ' + resp.status);
      const json = await resp.json();
      const text = (json && json.choices && json.choices[0] && json.choices[0].message
        && json.choices[0].message.content) || '{}';
      const parsed = JSON.parse(text);
      const verdict = String(parsed.verdict || '').trim();
      if (!['说', '不说', '拿不准'].includes(verdict)) {
        return skip('模型返回非法 verdict: ' + String(text).slice(0, 40), 'error');
      }
      const why = String(parsed.why || '').slice(0, 20);

      let release = '';
      let speak = verdict === '说' || verdict === '拿不准';

      if (verdict === '不说') {
        const quietMs = lastReplyAt > 0 ? Date.now() - lastReplyAt : 0;
        if (quietMs > cfg.quietReleaseMin * 60 * 1000) {
          release = 'quiet';
        } else if (cfg.loosePassRate > 0 && Math.random() < cfg.loosePassRate) {
          release = 'loose';
        }
        speak = !!release;
      }

      const id = Date.now().toString(36) + Math.random().toString(36).slice(2, 6);
      append({
        k: 'judge',
        id,
        t: Date.now(),
        key,
        tier,
        verdict,
        why,
        release,
        ms: Date.now() - t0,
        feats: featsOf(list, lastReplyAt),
        ctx: ctxOf(list),
      });

      const tag = verdict === '不说'
        ? (release ? `不说→放行(${release})` : '不说')
        : verdict;
      cfg.logger(`[judge] ${tag}：${why}`);

      return { speak, skipped: false, verdict, why, release };
    } catch (e) {
      const why = e && e.name === 'AbortError' ? '超时' : String((e && e.message) || e);
      cfg.logger('[judge] 异常放行：' + why);
      append({ k: 'judge', t: Date.now(), key, tier, verdict: 'skip', why: '异常放行：' + why, release: 'error', ms: Date.now() - t0, ctx: ctxOf(list) });
      return { speak: true, skipped: true, verdict: 'skip', why: '异常放行：' + why, release: 'error' };
    } finally {
      clearTimeout(timer);
    }
  }

  function stats() {
    return { day: usedDay || dayKey(), used, maxPerDay: cfg.maxPerDay, examples: cfg.examples.length };
  }

  return { shouldSpeak, stats, reloadExamples, exampleCount };
}

feedback.js 反馈闭环 CLI（242 行 · stats / list / label / build）
javascript
'use strict';

/**
 * feedback.js — 判官反馈闭环（零依赖，Node 18+）
 *
 * 流程：
 *   1. judge.js 每判一次，往 judge-log.jsonl 写一条（含 ctx）。
 *   2. node feedback.js list --unlabeled   看最近判了什么
 *   3. node feedback.js label <id> say|silence [--note "为什么"]
 *   4. node feedback.js build              把人工判例写成 examples.json
 *   5. judge.js 下次调用自动把 examples.json 拼进 prompt（few-shot）
 *
 * 这不是训练模型，是「判例学习」：人挑错、人标注、判官照着例子判。
 * 想让在跑的 HTTP 服务立刻生效：POST /reload（见 server.js）。
 *
 * 用法：
 *   node feedback.js stats
 *   node feedback.js list --unlabeled --limit 20
 *   node feedback.js list --verdict 不说 --limit 20
 *   node feedback.js label mabc123 say --note "点它名了"
 *   node feedback.js label mabc124 silence --note "别人互聊"
 *   node feedback.js build --max 8
 */

const fs = require('fs');

const DEFAULTS = { log: 'judge-log.jsonl', labels: 'labels.jsonl', out: 'examples.json' };

function readJsonl(file) {
  try {
    return fs.readFileSync(file, 'utf8').split('\n').filter(Boolean).map((line) => {
      try { return JSON.parse(line); } catch { return null; }
    }).filter(Boolean);
  } catch {
    return [];
  }
}

function parseArgs(argv) {
  const o = { _: [] };
  for (let i = 0; i < argv.length; i += 1) {
    const a = argv[i];
    if (a === '--limit') o.limit = Number(argv[++i]);
    else if (a === '--verdict') o.verdict = argv[++i];
    else if (a === '--unlabeled') o.unlabeled = true;
    else if (a === '--note') o.note = argv[++i];
    else if (a === '--log') o.log = argv[++i];
    else if (a === '--labels') o.labels = argv[++i];
    else if (a === '--out') o.out = argv[++i];
    else if (a === '--max') o.max = Number(argv[++i]);
    else o._.push(a);
  }
  return o;
}

function fmtTime(ts) {
  const d = new Date(Number(ts) || Date.now());
  const p = (n) => String(n).padStart(2, '0');
  return `${d.getFullYear()}-${p(d.getMonth() + 1)}-${p(d.getDate())} ${p(d.getHours())}:${p(d.getMinutes())}`;
}

function lastLabels(file) {
  const map = new Map();
  for (const l of readJsonl(file)) {
    if (l && l.id && (l.label === 'say' || l.label === 'silence')) map.set(l.id, l);
  }
  return map;
}

function statsOf(opts = {}) {
  const logFile = opts.log || DEFAULTS.log;
  const labelsFile = opts.labels || DEFAULTS.labels;
  const log = readJsonl(logFile).filter((r) => r.k === 'judge');
  const labels = lastLabels(labelsFile);
  const verdicts = {};
  const releases = {};
  for (const r of log) {
    const v = r.verdict || '?';
    verdicts[v] = (verdicts[v] || 0) + 1;
    if (r.release) releases[r.release] = (releases[r.release] || 0) + 1;
  }
  const byId = new Map(log.filter((r) => r.id).map((r) => [r.id, r]));
  let compared = 0;
  let agree = 0;
  for (const [id, l] of labels) {
    const r = byId.get(id);
    if (!r) continue;
    compared += 1;
    const want = l.label === 'say';
    const got = r.verdict === '说' || r.verdict === '拿不准';
    if (want === got) agree += 1;
  }
  return {
    total: log.length,
    verdicts,
    releases,
    labels: [...labels.keys()].filter((id) => byId.has(id)).length,
    compared,
    agree,
    agreeRate: compared ? agree / compared : null,
    logFile,
    labelsFile,
  };
}

function printStats(opts) {
  const s = statsOf(opts);
  console.log(`日志：${s.logFile}（判官记录 ${s.total} 条）`);
  console.log('判定分布：' + (Object.keys(s.verdicts).length
    ? Object.entries(s.verdicts).map(([k, v]) => `${k} ${v}`).join(' / ')
    : '（空）'));
  if (Object.keys(s.releases).length) {
    console.log('放行分布：' + Object.entries(s.releases).map(([k, v]) => `${k} ${v}`).join(' / '));
  }
  console.log(`人工标注：${s.labels} 条（能对上日志的）`);
  console.log(`标注与判官一致：${s.agree}/${s.compared}` +
    (s.agreeRate == null ? '' : `（${(s.agreeRate * 100).toFixed(0)}%）`));
  if (s.compared) console.log('提示：一致率低不一定是判官差，先看错在「该说没说」还是「不该说说了」。');
}

function listSamples(opts = {}) {
  const log = readJsonl(opts.log || DEFAULTS.log).filter((r) => r.k === 'judge' && r.id);
  const labels = lastLabels(opts.labels || DEFAULTS.labels);
  let rows = log.slice().sort((a, b) => (b.t || 0) - (a.t || 0));
  if (opts.verdict) rows = rows.filter((r) => r.verdict === opts.verdict);
  if (opts.unlabeled) rows = rows.filter((r) => !labels.has(r.id));
  const limit = Math.max(1, Number(opts.limit) || 20);
  rows = rows.slice(0, limit);
  if (!rows.length) { console.log('没有符合条件的记录。'); return rows; }
  for (const r of rows) {
    const mark = labels.has(r.id) ? (labels.get(r.id).label === 'say' ? '✓说' : '✓不说') : '  ?';
    const rel = r.release ? `→放行(${r.release})` : '';
    console.log(`${r.id}  ${fmtTime(r.t)}  ${r.key || '-'}  ${mark}  ${r.verdict}${rel}  ${r.why || ''}`);
    if (Array.isArray(r.ctx) && r.ctx.length) {
      const tail = r.ctx.slice(-3).map((m) => `${m.me ? '[它]' : ''}${m.s || '?'}: ${m.x || ''}`).join('  |  ');
      console.log('    ' + tail);
    }
  }
  return rows;
}

function labelSample(opts = {}) {
  const [id, label] = opts._ || [];
  if (!id || !['say', 'silence'].includes(label)) {
    throw new Error('用法：node feedback.js label <id> say|silence [--note "为什么"]');
  }
  const log = readJsonl(opts.log || DEFAULTS.log).filter((r) => r.k === 'judge');
  if (!log.some((r) => r.id === id)) throw new Error('日志里找不到 id：' + id);
  const rec = { id, label, note: String(opts.note || '').slice(0, 80), ts: Date.now() };
  fs.appendFileSync(opts.labels || DEFAULTS.labels, JSON.stringify(rec) + '\n', 'utf8');
  return rec;
}

function buildExamples(opts = {}) {
  const logFile = opts.log || DEFAULTS.log;
  const labelsFile = opts.labels || DEFAULTS.labels;
  const outFile = opts.out || DEFAULTS.out;
  const max = Math.max(1, Number(opts.max) || 8);

  const log = readJsonl(logFile).filter((r) => r.k === 'judge' && r.id
    && Array.isArray(r.ctx) && r.ctx.length);
  const byId = new Map(log.map((r) => [r.id, r]));
  const picks = [];
  for (const [id, l] of lastLabels(labelsFile)) {
    const r = byId.get(id);
    if (r) picks.push({ id, l, r });
  }
  picks.sort((a, b) => (b.r.t || 0) - (a.r.t || 0));

  const half = Math.ceil(max / 2);
  const say = picks.filter((p) => p.l.label === 'say').slice(0, half);
  const silence = picks.filter((p) => p.l.label === 'silence').slice(0, half);
  let sel = say.concat(silence);
  if (sel.length < max) {
    const used = new Set(sel.map((p) => p.id));
    sel = sel.concat(picks.filter((p) => !used.has(p.id)).slice(0, max - sel.length));
  }
  sel = sel.slice(0, max);

  const examples = sel.map(({ l, r }) => ({
    verdict: l.label === 'say' ? '说' : '不说',
    why: String(l.note || r.why || '').slice(0, 30),
    messages: r.ctx.map((m) => ({
      self: !!m.me,
      name: String(m.s || ''),
      text: String(m.x || ''),
      time: Number(m.t || 0) || undefined,
    })),
  }));

  let backup = '';
  try {
    if (fs.existsSync(outFile)) {
      backup = outFile + '.bak-' + new Date().toISOString().replace(/[:.]/g, '-');
      fs.copyFileSync(outFile, backup);
    }
  } catch { /* 备份失败不阻断 */ }
  fs.writeFileSync(outFile, JSON.stringify(examples, null, 2) + '\n', 'utf8');
  return {
    written: examples.length,
    say: examples.filter((e) => e.verdict === '说').length,
    silence: examples.filter((e) => e.verdict === '不说').length,
    file: outFile,
    backup,
  };
}

function usage() {
  console.log(`用法：
  node feedback.js stats
  node feedback.js list [--unlabeled] [--verdict 说|不说|拿不准] [--limit 20]
  node feedback.js label <id> say|silence [--note "为什么"]
  node feedback.js build [--max 8]
公共参数：--log judge-log.jsonl  --labels labels.jsonl  --out examples.json`);
}

    } else if (cmd === 'list') {
      listSamples(opts);
    } else if (cmd === 'label') {
      const rec = labelSample(opts);
      console.log(`已标注 ${rec.id} → ${rec.label}${rec.note ? '（' + rec.note + '）' : ''}`);
    } else if (cmd === 'build') {
      const r = buildExamples(opts);
      console.log(`已写 ${r.file}：${r.written} 条（说 ${r.say} / 不说 ${r.silence}）` +
        (r.backup ? `；旧文件备份到 ${r.backup}` : ''));
      console.log('让正在跑的服务立刻生效：POST /reload（或重启你的鱼）。');
    } else {
      usage();
    }
  } catch (e) {
    console.error(String((e && e.message) || e));
    process.exit(1);
  }
}

server.js HTTP 服务封装（147 行 · POST /judge · GET /health · POST /reload）
javascript
'use strict';

/**
 * server.js — 把判官包成 HTTP 服务（零依赖，Node 18+）
 *
 * 给「鱼不是 Node 写的」的人用：任何语言 POST 一下就能问该不该开口。
 *
 * 启动：
 *   node server.js --port 8787 --token 换成你的口令 --key sk-xxx
 *   # 或者：DEEPSEEK_API_KEY=sk-xxx JUDGE_TOKEN=xxx node server.js
 *
 * 调用：
 *   curl -s http://127.0.0.1:8787/judge \
 *     -H 'authorization: Bearer 换成你的口令' \
 *     -H 'content-type: application/json' \
 *     -d '{"messages":[{"name":"群友A","text":"今晚吃啥"},{"name":"群友B","text":"火锅"},{"name":"群友C","text":"@本鱼 你来吗"}],"opts":{"key":"group:123","tier":"chat","isGroup":true}}'
 *
 *   → {"speak":true,"skipped":false,"verdict":"说","why":"点它名了","release":""}
 *
 * 其它：
 *   GET  /health   → {"ok":true,"examples":3,"used":12}
 *   POST /reload   → 重新读 examples.json（反馈闭环用；需要口令）
 */

const http = require('http');
const { createJudge } = require('./judge');

function parseArgs(argv) {
  const o = {};
  for (let i = 0; i < argv.length; i += 1) {
    const a = argv[i];
    if (a === '--port') o.port = Number(argv[++i]);
    else if (a === '--host') o.host = argv[++i];
    else if (a === '--token') o.token = argv[++i];
    else if (a === '--key') o.key = argv[++i];
    else if (a === '--examples') o.examples = argv[++i];
    else if (a === '--log') o.log = argv[++i];
    else if (a === '--model') o.model = argv[++i];
    else if (a === '--base-url') o.baseUrl = argv[++i];
  }
  return o;
}

const opts = parseArgs(process.argv.slice(2));
const PORT = Number(opts.port || process.env.JUDGE_PORT) || 8787;
const HOST = opts.host || '127.0.0.1';
const TOKEN = String(opts.token || process.env.JUDGE_TOKEN || '');

const judge = createJudge({
  apiKey: opts.key || process.env.DEEPSEEK_API_KEY || '',
  baseUrl: opts.baseUrl,
  model: opts.model,
  examplesFile: opts.examples,
  logFile: opts.log || 'judge-log.jsonl',
  logger: (m) => console.log(`[judge-server] ${m}`),
});

function json(res, code, obj) {
  const body = JSON.stringify(obj);
  res.writeHead(code, {
    'content-type': 'application/json; charset=utf-8',
    'content-length': Buffer.byteLength(body),
  });
  res.end(body);
}

function authorized(req) {
  if (!TOKEN) return true;
  return req.headers.authorization === `Bearer ${TOKEN}`;
}

function readBody(req, limit = 256 * 1024) {
  return new Promise((resolve, reject) => {
    let size = 0;
    const chunks = [];
    req.on('data', (c) => {
      size += c.length;
      if (size > limit) {
        reject(new Error('body too large'));
        req.destroy();
        return;
      }
      chunks.push(c);
    });
    req.on('end', () => resolve(Buffer.concat(chunks).toString('utf8')));
    req.on('error', reject);
  });
}

const server = http.createServer(async (req, res) => {
  const url = (req.url || '/').split('?')[0];
  try {
    if (req.method === 'GET' && url === '/health') {
      return json(res, 200, { ok: true, examples: judge.exampleCount(), used: judge.stats().used });
    }

    if (url === '/reload' && req.method === 'POST') {
      if (!authorized(req)) return json(res, 401, { error: 'unauthorized' });
      const n = judge.reloadExamples();
      return json(res, 200, { ok: true, examples: n });
    }

    if (url === '/judge' && req.method === 'POST') {
      if (!authorized(req)) return json(res, 401, { error: 'unauthorized' });
      let body;
      try {
        body = JSON.parse((await readBody(req)).replace(/^\uFEFF/, ''));
      } catch {
        return json(res, 400, { error: 'body 不是合法 JSON（或超过 256KB）' });
      }
      const messages = body && body.messages;
      if (!Array.isArray(messages) || !messages.length) {
        return json(res, 400, { error: 'messages 必须是非空数组' });
      }
      const callOpts = (body && body.opts) || {};
      const out = await judge.shouldSpeak(messages, callOpts);
      return json(res, 200, out);
    }

    if (url === '/judge' || url === '/reload') {
      return json(res, 405, { error: 'method not allowed' });
    }
    return json(res, 404, { error: 'not found' });
  } catch (e) {
    console.error('[judge-server] 500', e);
    return json(res, 500, { error: String((e && e.message) || e) });
  }
});

server.on('error', (e) => {
  console.error('[judge-server] 启动失败：' + String((e && e.message) || e));
  process.exit(1);
});

server.listen(PORT, HOST, () => {
  console.log(`[judge-server] http://${HOST}:${PORT}  model=${opts.model || 'deepseek-chat'} ` +
    `examples=${judge.exampleCount()}  auth=${TOKEN ? 'on' : 'off'}`);
  if (!TOKEN) console.log('[judge-server] 没设口令（--token / JUDGE_TOKEN）；只监听本机时可以不管。');
});

for (const sig of ['SIGINT', 'SIGTERM']) {
  process.on(sig, () => {
    console.log('\n[judge-server] 关闭');
    server.close(() => process.exit(0));
    setTimeout(() => process.exit(0), 1500);
  });
}
selftest.js 离线自测套件（124 行 · mock 模型、12 项断言、不花 token）
javascript
'use strict';

/**
 * selftest.js — 离线自测（不连网，不花 token）
 * 运行：node selftest.js
 */

const fs = require('fs');
const os = require('os');
const path = require('path');

const { createJudge } = require('./judge');
const fb = require('./feedback');

let pass = 0;
let fail = 0;
function ok(name, cond, extra) {
  if (cond) {
    pass += 1;
    console.log('PASS ' + name);
  } else {
    fail += 1;
    console.log('FAIL ' + name + (extra ? '  ' + extra : ''));
  }
}

let lastBody = null;
let mode = 'say';

global.fetch = async (url, init) => {
  lastBody = JSON.parse(init.body);
  const content = mode === 'say'
    ? '{"verdict":"说","why":"在问它"}'
    : '{"verdict":"不说","why":"别人互聊"}';
  return { ok: true, json: async () => ({ choices: [{ message: { content } }] }) };
};

function judgeFile(tmp) {
  return path.join(tmp, 'judge-log.jsonl');
}

(async () => {
  const tmp = fs.mkdtempSync(path.join(os.tmpdir(), 'judge-kit-'));
  try {
    const msgs = [
      { self: false, name: 'A', text: '今天吃啥', time: Date.now() - 120000 },
      { self: false, name: 'B', text: '火锅', time: Date.now() - 60000 },
      { self: false, name: 'C', text: '@本鱼 你来吗', time: Date.now() },
    ];

    const j = createJudge({ apiKey: 'x', logFile: judgeFile(tmp), loosePassRate: 0, quietReleaseMin: 25 });
    let r = await j.shouldSpeak(msgs, { isGroup: true, tier: 'chat', key: 'group:test' });
    ok('说 → speak', r.speak === true && r.verdict === '说' && !r.skipped, JSON.stringify(r));

    r = await j.shouldSpeak(msgs, { isGroup: true, tier: 'high' });
    ok('高档 → skip', r.speak === true && r.skipped === true, JSON.stringify(r));

    r = await j.shouldSpeak(msgs, { isGroup: false, tier: 'chat' });
    ok('私聊 → skip', r.speak === true && r.skipped === true, JSON.stringify(r));

    mode = 'no';
    r = await j.shouldSpeak(msgs, { isGroup: true, tier: 'chat' });
    ok('不说 → 沉默', r.speak === false && r.verdict === '不说' && !r.release, JSON.stringify(r));

    r = await j.shouldSpeak(msgs, {
      isGroup: true, tier: 'chat', lastReplyAt: Date.now() - 30 * 60 * 1000,
    });
    ok('不说 → 静默释放', r.speak === true && r.release === 'quiet', JSON.stringify(r));

    const jLoose = createJudge({ apiKey: 'x', logFile: '', loosePassRate: 1 });
    r = await jLoose.shouldSpeak(msgs, { isGroup: true, tier: 'chat' });
    ok('宽松率 1 → 放行', r.speak === true && r.release === 'loose', JSON.stringify(r));

    // 判例加载
    const exFile = path.join(tmp, 'examples.json');
    fs.writeFileSync(exFile, JSON.stringify([{
      verdict: '不说',
      why: '别人互聊',
      messages: [{ name: 'A', text: '今晚吃啥' }, { name: 'B', text: '火锅' }, { name: 'A', text: '走' }],
    }]), 'utf8');
    mode = 'say';
    const jEx = createJudge({ apiKey: 'x', logFile: '', examplesFile: exFile });
    await jEx.shouldSpeak(msgs, { isGroup: true, tier: 'chat' });
    ok('examples 加载计数', jEx.exampleCount() === 1, String(jEx.exampleCount()));
    ok('system prompt 含判例', !!(lastBody && lastBody.messages[0].content.includes('参考判例')
      && lastBody.messages[0].content.includes('火锅')), '');

    // feedback 闭环
    const fbLog = path.join(tmp, 'fb-log.jsonl');
    const fbLabels = path.join(tmp, 'fb-labels.jsonl');
    const fbOut = path.join(tmp, 'fb-examples.json');
    const ctx1 = [{ me: false, s: 'A', x: '今晚吃啥', t: 1 }, { me: false, s: 'B', x: '火锅', t: 2 }];
    const ctx2 = [{ me: false, s: 'A', x: '@本鱼 你来吗', t: 3 }];
    fs.writeFileSync(fbLog, [
      JSON.stringify({ k: 'judge', id: 'a1', t: 1, key: 'group:1', verdict: '不说', why: '别人互聊', ctx: ctx1 }),
      JSON.stringify({ k: 'judge', id: 'a2', t: 2, key: 'group:1', verdict: '说', why: '点它名了', ctx: ctx2 }),
    ].join('\n') + '\n', 'utf8');
    fs.writeFileSync(fbLabels, [
      JSON.stringify({ id: 'a1', label: 'silence', note: '确实没叫它' }),
      JSON.stringify({ id: 'a2', label: 'say', note: '点它名了' }),
    ].join('\n') + '\n', 'utf8');

    const built = fb.buildExamples({ log: fbLog, labels: fbLabels, out: fbOut, max: 4 });
    const ex = JSON.parse(fs.readFileSync(fbOut, 'utf8'));
    ok('build 写出 2 条', built.written === 2 && ex.length === 2, JSON.stringify(built));
    ok('build 两类各 1', ex.filter((e) => e.verdict === '说').length === 1
      && ex.filter((e) => e.verdict === '不说').length === 1, JSON.stringify(ex.map((e) => e.verdict)));

    const st = fb.statsOf({ log: fbLog, labels: fbLabels });
    ok('stats 总数/标注/一致', st.total === 2 && st.labels === 2 && st.compared === 2 && st.agree === 2,
      JSON.stringify(st));

    const rec = fb.labelSample({ _: ['a2', 'silence'], note: '改判', log: fbLog, labels: fbLabels });
    ok('label 追加', rec.id === 'a2' && rec.label === 'silence' && rec.note === '改判', JSON.stringify(rec));
  } finally {
    try { fs.rmSync(tmp, { recursive: true, force: true }); } catch { /* ignore */ }
  }

  console.log(`\n${pass} passed, ${fail} failed`);
  process.exit(fail ? 1 : 0);
})().catch((e) => {
  console.error(e);
  process.exit(1);
});
