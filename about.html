把表情库接进你的项目

本站是纯静态站，没有服务端随机接口，也不需要申请密钥。完整表情清单直接公开，网页、机器人和脚本都能读取，图片同样允许跨域。

GET https://fisharchive.cc/stickers/index.json ↗
  • count 与 stickers[]，条目数以此为准
  • alt、tags、width、height
  • author（社区投稿的署名）与 selfMade（站长自作）
  • page（图片所在页面）与 credit（推荐出处文本）
  • original / large / preview 三个绝对地址

跨域响应头已配置 · 机器可读说明见 llms.txt · 图片站点地图见 sitemap-images.xml

随机取一张 · 浏览器控制台 

(async () => {
  const res = await fetch(
    'https://fisharchive.cc' +
    '/stickers/index.json'
  );
  if (!res.ok) throw new Error(`请求失败: ${res.status}`);
  const { stickers } = await res.json();
  if (!stickers.length) throw new Error('清单为空');
  const pick = stickers[Math.floor(
    Math.random() * stickers.length
  )];
  const img = document.createElement('img');
  img.src = pick.large; // original 为原图
  img.alt = pick.alt;
  document.body.append(img);
})();

这是一个什么站

一个非官方、无广告、由爱好者与群友共同维护的同人档案馆，不代表任何官方立场，也不对站内作品另行主张权利。

无论是收拢同人表情、整理角色立绘，还是分享 DSH 养鱼教程与插件，站内都尽量保留「原貌」：图片不加水印、不改格式、不降低分辨率，教程步骤与报错表全部来自实测，方便后来的人直接拿去用。
